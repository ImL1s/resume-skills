## 2026-08-01 in-session UX audit (plans 045–055)

Generated by `/improve` on **2026-08-01** against commit **`2b4611c`**
(`main`). Scope: the **in-session experience** — a host agent activating a
`resume-<source>` Skill, running the bundled reader, and consuming the inert
handoff. Three lenses: `SKILL.md` as prompt engineering for a weaker model;
the handoff document as an LLM-consumed payload; and the full end-to-end loop
walked from a real temp install (including against this machine's real Claude
store, read-only).

Not audited: host-native activation UI (still `not-run` per `docs/STATUS.md`),
non-Claude adapters' tool-evidence handling beyond a reported inventory,
translation quality of the localized guides, Windows.

**Headline finding**: the handoff systematically discards *what the previous
agent actually did* — tool calls are dropped for the flagship Claude source,
results render as anonymous blobs, and "Latest assistant action" reports stale
intent when a session is interrupted mid tool-loop (the dominant resume case).
Plans 045–047 fix that chain.
